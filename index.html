Run for Ellis

Bryce Montano is running his seventh 100-miler — Run Rabbit Run — for Ellis and for the kids at St. Jude.

Donate Get the shirt Track the run

Why this run

Ellis is Dave McDaniel’s son. He is fighting osteosarcoma — a hard road of chemo and surgery. Bryce, a friend and former colleague, is lining up at Run Rabbit Run so the miles can stand for Ellis and for St. Jude.

If you want to help, the most direct ways are Bryce’s GoFundMe for St. Jude (“Running for Ellis”) and the Running for Ellis tee.
